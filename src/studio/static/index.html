A second pair of eyes

REVIEW

Checks flag structural problems. Compare pitches, rhythms, clefs, accidentals and expressive marks with the original.

Start with the structure

1. Count parts against the PDF. SATB + piano normally has five parts.
2. Check the opening time signature. A missing meter causes many false rhythm warnings.
3. Then compare pitches and rhythms, one bar at a time. Display bar numbers can differ after a bad scan.

Correct a time signature

Changes the meter from this bar onward until the next time change. It does not add missing notes or repair part assembly.
